## Featured Project

### AgentDoctor

**Project intelligence & assurance for developers and engineering teams**

Repository analysis · Safety controls · MCP · CLI · Open Source

[![npm](https://img.shields.io/npm/v/@praneeth_54/agentdoctor?label=npm)](https://www.npmjs.com/package/@praneeth_54/agentdoctor)
[![CI](https://img.shields.io/github/actions/workflow/status/pranee54/AgentDoctor/ci.yml?branch=main&label=CI)](https://github.com/pranee54/AgentDoctor/actions/workflows/ci.yml)
[![License: MIT](https://img.shields.io/badge/license-MIT-blue.svg)](https://github.com/pranee54/AgentDoctor/blob/main/LICENSE)

AgentDoctor helps people understand, plan, safely change, test, secure, and verify software projects — whether the code was written by hand, with AI, or by a coding agent. Repository evidence is the source of truth; the model only reasons.

```text
UNDERSTAND → ASK → PLAN → APPROVE → CHANGE → TEST → SECURE → VERIFY → PROVE
```

**Explore:** [Repository](https://github.com/pranee54/AgentDoctor) · [npm](https://www.npmjs.com/package/@praneeth_54/agentdoctor) · [Docs](https://github.com/pranee54/AgentDoctor/tree/main/docs)

```bash
npm i -g @praneeth_54/agentdoctor
agentdoctor start
agentdoctor learn .
```
